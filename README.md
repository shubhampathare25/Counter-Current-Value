## Count-Current-Value
A simple and interactive counter application built with React and Redux.
This app allows users to increment, decrement, and reset a counter value, with optional privacy mode to hide the current value.

## Features
* Increment, decrement, and reset the counter
* Privacy mode to hide/show the current value
* Clean and responsive user interface
* State management using Redux
* Built with React and Vite for fast performance

Getting Started
1. Clone the repository:
 ```
   git clone https://github.com/your-username/Count-Current-Value.git
    cd Count-Current-Value
```
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
```
   npm run dev
```
4. Open http://localhost:5173 in your browser to use the counter.
